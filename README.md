# Git-Workshop
Repositório usado na parte prática da oficina de Git.

A atividade será feita em grupos de 3 ou 4 pessoas. Cada integrante trabalhará em uma branch própria e, no final, as alterações serão reunidas na `main` por meio de Pull Requests.

O repositório contém um arquivo de texto simples que será utilizado durante a prática.

Cada integrante do grupo deverá:

1. Criar sua própria branch.
2. Fazer alterações no arquivo.
3. Criar pelo menos um commit.
4. Enviar a branch para o GitHub.
5. Abrir um Pull Request para a `main`.
